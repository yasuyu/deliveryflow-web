# 機能一覧

この文書は、DeliveryFlow Webの機能をID付きで管理し、現在の実装状況と確認場所を対応させます。実装の詳細はコード、Migration、[OpenAPI文書](openapi.yaml)、自動テストを正とします。

## 状態の意味

| 状態 | 意味 |
|---|---|
| 実装済み | 画面またはAPIがあり、自動テストで主要動作を確認している |
| 一部実装 | 基本動作はあるが、本来想定する範囲の一部だけを扱う |
| 未実装 | 現在のコードには含まれず、将来候補として記録している |

## 配達員と認証

| ID | 機能 | 状態 | 確認場所 |
|---|---|---|---|
| D-01 | 配達員の登録と6桁PINログイン | 実装済み | Web画面、`POST /api/drivers`、`POST /api/login` |
| D-02 | BearerトークンによるAPI認証 | 実装済み | 認証が必要な`/api`エンドポイント |
| D-03 | ログアウトとトークン無効化 | 実装済み | `POST /api/logout` |
| D-04 | PINの連続失敗に対する一時的なログイン拒否 | 実装済み | APIテスト |
| D-05 | 勤務開始、退勤、勤務中ログアウトの制限 | 実装済み | `POST /api/shifts/start`、`POST /api/shifts/end` |

| O-06 | 状態変更POSTの重複実行防止 | 実装済み | `Idempotency-Key`、DB一意制約 |
