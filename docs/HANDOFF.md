# 新しいチャットへの引き継ぎ

作業開始時に、プロジェクト直下のAGENTS.mdも必ず読むこと。
AGENTS.md、README.md、docs/PROJECT_STATUS.mdの指示を優先すること。
外部の参考資料は公開物へ転記せず、必要な要件の確認にだけ使用すること。

## 現在の作業対象

- 配達・地図画面のルート表示、受取地点・配達先、料金、進行状態
- `OFFERING → ASSIGNED → PICKED_UP → DELIVERED`に対応する案内と操作
- 配達員の正確な現在地座標は画面へ返さず、店舗・届け先は学習用の仮座標として扱う
- 参考資料は読み取り専用とし、個人パスやSecretをリポジトリ、PR、チャットへ残さない

## 実装時の確認事項

- オファー、受諾、受取、完了、期限切れ、辞退、取り下げの状態遷移
- 店舗・届け先の経路表示と状態別案内
- 現在地、候補選定、見込みスコア、ランキング、冪等な状態変更
