API CONTRACT

状態遷移を守るAPI

画面や他のクライアントがサーバーをどう呼ぶかを決める契約書です。実際のOpenAPIファイルは openapi.yaml です。

認証済みのPOSTには Idempotency-Key が必要です。同じキーの再送には保存済みの結果を返すため、二重操作を防げます。

エンドポイント

GET /api/dashboard
現在の配達員・オファー・配達を取得し、期限切れも反映
POST /api/shifts/start
OFFLINE → IDLE
POST /api/shifts/end
IDLE → OFFLINE、またはOfferを暗黙に辞退してOFFERED → OFFLINE
POST /api/offers/current
IDLE → OFFERED
POST /api/offers/:id/accept
DriverはBUSY、OrderはASSIGNED、他のOfferはWITHDRAWN
POST /api/offers/:id/reject
DriverはIDLE、OfferはREJECTED
POST /api/assignments/:id/pickup
ASSIGNED → PICKED_UP
POST /api/assignments/:id/complete
PICKED_UP → DELIVERED、DriverはIDLE

WHY OPENAPI

iOS版、Web版、バックエンドが同じAPIの形を共有できます。実装を変える前に契約を更新すれば、チーム開発での認識ずれを減らせます。
